# MEASH CLEANING SOLUTION - Telegram Mini App

Official Telegram Mini App for **MEASH CLEANING SOLUTION** (አዲስ አበባ ፣ ኢትዮጵያ).

## Features
- 🚀 **1-Tap Booking**: Fast, interactive booking in Amharic (አማርኛ) and English.
- 📍 **Live GPS Pinpoint Geolocation**: Real-time GPS coordinate capture using HTML5 Geolocation API.
- 🛋 **Services & Instant Pricing**: Live estimates for Sofas, Carpets, Mattresses, and Glass cleaning.
- 🏢 **10 Addis Ababa Subcities**: Bole, Yeka, Kirkos, Lideta, Nifas Silk, Kolfe, Arada, Gulele, Akaki, Lemi Kura.
- 📱 **Native Telegram Integration**: Seamlessly sends booking data to `@meash_cleaning_solution_bot` via `Telegram.WebApp.sendData()`.
